交付物：本 PRD + 第九章《详细修改指令清单》（可直接分段粘贴给 AI 编码工具执行）

## 一、问题诊断（现状痛点）

结合截图（驾驶舱 / 资金主线 / 个股雷达 / 消息面）逐页检视，当前产品的本质是"**行情数据聚合器**"，而非"**决策引擎**"。具体表现：

| 现状 | 游资视角下的问题 |
|---|---|
| 主线作战卡展示了"第一/第二/第三主线"，但都是**同权重并列展示** | 游资只信"唯一最强主线"，其余都是噪音。并列展示 = 没有做出选择，等于没有决策 |
| 情绪温度计只有一个"49分/中性"的静态分数 | 游资看的是"情绪所处的周期阶段"（启动→加速→分歧→退潮→冰点），单一分数无法指导"现在该进还是该退" |
| 异动信息（自选异动、人气榜拥挤度）是**事后罗列**，没有分钟级/秒级的"第一时间"提示 | 游资的核心能力是"抢跑"，异动出现后 30 秒到 3 分钟是黄金决策窗口，现在的看板是"复盘用的"，不是"作战用的" |
| AI（Agnes 2.5 Flash）目前只出现在个股页做"AI研判"、消息面做"AI要点"，且都是**大段文字总结** | 游资要的不是总结，是结构化的"能不能上车 / 现在是什么位置 / 止损在哪 / 风险是什么"的四要素决策卡，且要能追问 |
| 资金主线页把"概念板块资金流排行"按今日净流入金额简单排序 | 金额大不等于主线强，游资判断主线要看"涨停家数占比、连板高度、晋级率、赚钱效应、资金连续性"综合打分，现在完全没有主线强度评分体系 |
| 龙虎榜复盘页（截图未展开但导航中存在）大概率也只是"数据罗列" | 应该做"游资席位画像库 + 一致性/抱团/接力识别"，这是判断资金性质和是否可跟的关键 |
| 消息面页把公告/快讯做了星级和利好利空标注，但和主线、个股没有联动 | 一条利好新闻如果不能自动关联到"会催化哪个板块、哪些股票会因此进入主线候选池"，就只是新闻，不是情报 |
| 全站没有"退潮/离场"信号的强提示 | 游资亏钱往往不是没抓到主线，而是主线退潮时没有跑。产品必须把"离场信号"做得和"进场信号"一样显眼，甚至更显眼 |

**一句话总结现状**：产品把"是什么（What）"做到了 90 分，但完全没有回答游资真正要的"现在该怎么做（So What / Now What）"。

## 二、产品定位重新定义

**旧定位**：A股实时监控终端（信息聚合 + 可视化）

**新定位**：**游资级主线决策系统（Mainline Decision Engine）**
一句话价值主张：**"3 秒告诉我今天最强的主线是什么、现在是什么阶段、我该不该上车、什么时候该跑。"**

设计哲学转变：

1. 从"全量展示"转向"强制排序 + 唯一推荐"——任何列表类信息都必须给出"Top1 / 唯一主线 / 唯一操作建议"，其余作为备选折叠。
2. 从"事后统计"转向"事中捕捉"——引入秒级/分钟级异动引擎，强调"首次触发"时间戳和"黄金决策窗口倒计时"。
3. 从"数据陈述句"转向"决策指令句"——所有 AI 输出必须是结构化卡片（结论先行：能/不能/观望 + 理由 + 风险 + 止损位），不是段落摘要。
4. 从"单点 AI 调用"转向"AI 决策大脑常驻"——Agnes 2.5 Flash 应作为贯穿全站的"值班分析师"，主动推送、可追问、可复盘学习。
5. 从"看多不看空"转向"进出同等重要"——每个主线/个股必须同时呈现"强度分"和"退潮风险分"。

## 三、游资决策五要素模型（贯穿全产品的核心方法论）

所有页面、所有 AI 输出必须服务于以下五个问题，产品要在 UI 上让这五个问题"永远可见"：

1. **主线是什么？**（Which：唯一最强主线识别）
2. **主线处于什么阶段？**（When：启动/加速/分歧/退潮/冰点）
3. **谁是龙头/卡位股？**（Who：核心受益股 vs 跟风股）
4. **现在能不能上车？怎么上？**（How：仓位建议、买点、止损）
5. **什么信号出现说明要跑？**（Exit：离场触发条件）

建议在驾驶舱页顶部常驻一个"**游资五问条**"，AI 实时回答这五句话（见第五章 5.1）。

## 五、分模块详细需求

### 5.1 驾驶舱页 —— 决策台重构

**新增「游资五问条」**（页面最顶部，仅次于全局指数带，常驻不可折叠）：
- 展示形式：5 个卡片横排，Agnes 每 60 秒自动刷新一次结论，字数严格限制（每卡 ≤ 20 字结论 + ≤ 20 字理由）
- 字段：
  1. 主线：XX（强度 92 分）
  2. 阶段：加速期（较昨日+1 档）
  3. 龙头：XX股（核心逻辑：xxx）
  4. 操作：可轻仓试错 / 可加仓 / 只看不做 / 应离场（4 选 1，用红黄绿灰四色强区分）
  5. 离场信号：尚未触发 / 已触发（xxx）

**"今日主线作战卡"改造**：
- 去掉"第一/第二/第三主线"并列平权的展示方式，改为**强制排序 + 强度分**：每条主线卡片右上角显示"主线强度分（0-100）"大字号数字，按分数从高到低排列，仅金分（≥80）主线默认展开，其余折叠为一行。
- 每张主线卡片新增字段：
  - 主线强度分（算法见 6.1）
  - 阶段标签（启动/加速/分歧/退潮/冰点，见 6.2）
  - 持续性预测（AI 给出：预计可持续 X 个交易日 + 置信度）
  - 核心逻辑 vs 蹭热点 龙头股分类（见 6.3）
  - "现在参与价值"三色徽章：绿=可参与，黄=谨慎参与，红=不建议参与
  - 一键"追问 Agnes"按钮，点击弹出该主线的深度决策卡（结构见 7.2）

**情绪温度计改造**：
- 保留 0-100 分数，但下方新增"情绪周期进度条"，把周期分为 5 段（冰点/启动/加速/主升分歧/退潮），当前分数对应到具体阶段并高亮，而不是单纯给一个孤立分数。
- 新增"距离上一次同阶段发生了什么"的历史案例提示（如"上次情绪49分+加速期，次日高度下降概率68%"），由 AI 基于历史样本库生成（若无真实历史数据库，先用可配置的规则引擎模拟，接口预留给未来真实回测数据）。

**新增"退潮预警条"**（红色，仅在触发时出现，位置在情绪温度计下方，比现有的"重度背离"通知条更具体到"主线级别"）：
- 触发条件示例：连续 2 个交易日涨停家数环比下降 >30%、最高板高度下降、炸板率突然上升、主力资金转为流出且散户资金流入（已有该逻辑，需要和"主线阶段"挂钩，而不是只挂钩大盘）

**"自选异动"模块升级为"异动捕捉引擎"**（见 5.6 全局能力，UI 挂载在此）

**"持仓×主线匹配"升级**：
- 新增"持仓健康度诊断"：AI 自动判断每只持仓股是"主线核心票/主线跟风票/脱离主线孤立票/伪主线票"，并给出继续持有/减仓/清仓建议，附一句话理由。

### 5.2 资金主线页 —— 升级为"主线强度引擎"

**新增模块："主线强度排行榜"（页面最顶部，替代原来平铺的资金结构详情作为首屏）**
- 表格字段：排名 / 板块名称 / 主线强度分 / 阶段 / 涨停家数(占比) / 连板高度 / 晋级率 / 换手率 / 资金净流入(今日/5日/10日) / 龙头股 / AI一句话诊断 / 操作建议
- 排序默认按"主线强度分"，而非资金净流入金额
- 强度分 ≥ 80 的板块标红名，代表"当前最强主线候选"

**"概念板块资金流排行"保留，但增加"资金流≠主线强度"的提示语**，并在表格中新增一列"是否为强度榜Top5"，避免用户仅凭金额误判。

**"资金连续性"模块增加"主线切换雷达"**：当近 5 日资金流向出现"从 A 板块切到 B 板块"的迹象时，主动弹出提示："资金正从 XX 板块转向 YY 板块，警惕主线切换"。

**明暗盘资金流向监控**：保持现状数据结构，但增加"主力真实动向"AI 解读一句话（如"明盘净流入但暗盘净流出，判断为尾盘对倒护盘，非真实进场"）。

---

### 5.3 个股雷达页 —— 升级为"个股决策卡"

现状：右侧信息流是"资金面/资金结构/消息面/公告"的时间线罗列 + 顶部一个"AI详细研判"按钮（未展开内容）。

**改造为**：
1. 顶部常驻"个股决策卡"（默认展开，替代原来空的等待区），结构固定为：
   - 一句话结论（能不能参与，仓位建议）
   - 主线归属（是否在主线中，第几主线，核心/跟风/孤立）
   - 技术位置（相对高低位、量能状态）
   - 资金性质（主力/游资/散户，是否有知名游资席位介入——联动龙虎榜画像）
   - 风险点（≤2条，最重要的放前面）
   - 止损/止盈参考位（仅供参考，标注免责声明）
   - 置信度（0-100，AI自评）
2. "AI批量扫描"按钮改为**自动触发**：自选股列表中任意一只出现异动（涨跌幅、量比、换手率触发阈值），自动重新生成该股决策卡并置顶+红点提醒+可选语音播报。
3. 信息流（资金面/消息面/公告）保留，但每条后面增加 AI 自动打的"信号标签"（利好/利空/中性 + 对股价影响时效：即时/次日/长期）。

---

### 5.4 龙虎榜复盘页 —— 升级为"游资画像与资金性质识别"

（当前导航中已有入口，需从"数据罗列"升级为"决策辅助"）

1. **知名游资席位库**：建立/接入席位名称库（如"章盟主""赵老哥""炒股养家"类营业部特征），当某股票龙虎榜出现已知游资席位时，打标签"知名游资：XXX 介入"。
2. **资金一致性判断**：AI 自动判断"多个游资是否在同一只股票形成合力（一致性买入）"还是"多空对倒（分歧出货）"，给出"抱团/接力"或"对倒/出货"标签。
3. **接力强度打分**：针对涨停梯队，计算"次日溢价率历史统计 + 今日封单强度"，给出"建议冰点/半路/追高"三档接力建议。

---

### 5.5 消息面页 —— 升级为"情报转信号中心"

1. 每条快讯/公告除现有的星级和利好利空标注外，新增字段：
   - **关联主线**：AI 自动判断该消息属于/催化哪个当前监控中的板块（若命中当前主线榜单，高亮显示"⚡命中今日主线"）
   - **是否已被定价**：AI 判断消息发布时间与相关个股/板块涨幅的关系，给出"尚未反应/已部分反应/已充分反应"判断
   - **建议动作**：关注/无需操作/立即核实（针对重大且未反应的消息）
2. **"AI要点"模块升级为"情报晨报/午报/收评"三个时间点自动生成**，采用结构化输出：今日主线催化梳理 → 明日潜在主线预判 → 需要规避的风险事件。
3. 新增"情报-主线联动看板"：把消息面命中的板块，实时同步到驾驶舱的"主线作战卡"里作为催化剂标签来源（打通数据流，避免消息面和主线是两套孤立系统）。

### 5.6 全局能力：异动捕捉引擎（Real-time Anomaly Engine）

这是本次改造的**最核心的新增能力**，需要贯穿驾驶舱、个股雷达、消息面三处。

**异动分级定义**：

| 等级 | 触发条件示例 | 处理方式 |
|---|---|---|
| S级（紧急） | 涨停封单/开板、20cm 快速拉升、龙虎榜知名游资实时现身、重大利好公告首次出现 | 强提醒：红色闪烁 + 声音播报 + 弹窗，附带 AI 一句话研判（5 秒内可读完） |
| A级（重要） | 量比>5异常放量、换手率>15%、快速拉升>7%/5分钟、涨速排行前列 | 中提醒：列表置顶 + 高亮，AI 一句话研判 |
| B级（关注） | 温和放量、连续3日资金净流入转正、题材小幅异动 | 弱提醒：常规列表展示 |

**异动卡片统一结构**（用于 S/A 级弹窗和列表）：
- 时间戳（精确到秒）+"距首次触发 X 分钟"倒计时黄金窗口提示
- 股票/板块名称
- 触发原因（如"3分钟内量比从1.2冲到6.8"）
- 是否呼应当前主线（是/否 + 呼应哪条主线）
- AI 一句话研判 + 建议动作（观察/可小仓试错/无需操作）

**技术实现建议（供编码 AI 参考，非本次前端 mock 数据也要预留结构）**：
- 建立一个本地/模拟的"异动事件流"数据结构（events[]），每个 event 包含 level/type/timestamp/stock/reason/aiComment 字段，前端轮询或 mock 定时器推送，UI 组件统一订阅渲染，方便未来接入真实 tick 级数据源。

## 六、核心算法与规则规范（给编码 AI 的明确公式，避免臆造 UI 而无逻辑）

### 6.1 主线强度分（0-100，权重可在设置中调整，默认如下）

```
主线强度分 =
  涨停家数占比得分 × 25% +
  连板高度得分 × 20% +
  晋级率得分 × 15% +
  资金连续性得分（5日+10日净流入趋势）× 20% +
  换手/量能活跃度得分 × 10% +
  催化剂强度得分（政策/事件/资金三类，AI从消息面联动打分）× 10%

各子项统一归一化到 0-100 分再加权求和
```

### 6.2 主线阶段判定（规则引擎，非玄学）

```
启动期：涨停家数环比连续2日上升，且龙头位置低（无连续3板以上）
加速期：涨停家数持续高位，最高板高度上升，晋级率>50%
主升分歧期：最高板不再创新高，炸板率上升但涨停总数仍多
退潮期：涨停家数环比下降>30%，或最高板高度连续2日下降，或主力资金转流出
冰点期：板块连续3日以上涨停家数<3只，资金流入排名跌出前20
```

### 6.3 龙头股分类规则

```
核心逻辑股：涨停原因含"业绩驱动/独家资质/技术壁垒关键词" 且 机构/主力资金net inflow为正
卡位股：题材相关但业绩/资质关联度低，靠资金/情绪驱动
跟风/蹭热点股：涨停原因关键词命中"改名/蹭热点/无业绩支撑"，或近5日无资金持续净流入
```

### 6.4 离场（退潮）信号规则（务必与主线阶段联动，而不仅是大盘层面）

```
触发任一即弹出红色预警：
1. 该主线炸板率单日环比上升 ≥ 15个百分点
2. 该主线涨停家数环比下降 ≥ 30%
3. 该主线最高板较昨日下降 ≥ 1 档，且连续 2 日
4. 该主线内主力资金由净流入转净流出，且散户资金转净流入（游资出、散户接）
```

## 七、Agnes（2.5 Flash）AI 决策大脑架构与 Prompt 规范

### 7.1 定位

Agnes 不再是"被动调用一次生成一段话"的工具，而是**常驻值班分析师**，具备：
- 主动播报（异动触发时自动生成研判，无需用户点按钮）
- 结构化输出（严格 JSON 结构，前端渲染为卡片，不允许自由大段文字）
- 多轮追问（用户可针对任意卡片继续追问，携带上下文：当前主线/个股/最近N条异动作为 context）
- 复盘学习（收盘后自动生成复盘报告，次日开盘前推送"今日关注清单"）

### 7.2 结构化输出 Schema（示例，供编码 AI 直接实现为 JS 对象/接口约定）


### 7.3 Prompt 模板（供编码 AI 直接写入系统提示词/调用逻辑）

**主线诊断 Prompt 模板**：
```
你是一名资深A股游资操盘手，擅长在盘中第一时间判断最强主线。
基于以下实时数据：{涨停梯队数据}、{板块资金流数据}、{消息面催化数据}，
请按以下JSON结构输出对「{板块名}」的诊断：
strength_score(0-100)、stage(启动/加速/主升分歧/退潮/冰点)、
sustain_forecast、leader(core/follower/hype三类股票)、
action(一句话操作建议，必须是"可参与/谨慎参与/不建议参与"三选一开头)、
risk(最多2条，按重要性排序)、exit_signal_triggered(true/false)、confidence(0-100)。
要求：结论先行，语言简练，禁止使用模糊词汇（如"或许""可能"），
必须给出明确可执行的判断。若数据不足以支撑判断，confidence需低于50并说明缺失的数据。
```

**异动研判 Prompt 模板**：
```
你是游资盘中异动监控助手。收到一条异动事件：{股票/板块}、{触发原因}、{当前主线列表}。
请在10个字以内给出该异动"是否呼应主线"，20个字以内给出"建议动作"，
输出必须是JSON，不允许输出多余解释文字。
```

**收盘复盘 Prompt 模板**：
```
你是游资操盘手，请基于今日主线强度排行、涨停梯队数据、异动记录，
生成收盘复盘报告，包含：
1. 今日实际最强主线是什么，强度分多少，事后验证与盘中判断是否一致
2. 今日误判的地方（如盘中判断为主线但实际未走出来的板块）
3. 明日重点关注的1-2个潜在主线及理由
4. 一句话情绪总结（乐观/中性/谨慎/悲观）
输出结构化 JSON，字段：actual_mainline, verification_result, misjudgment, tomorrow_watch[], sentiment_summary
```

### 7.4 交互规范

- 任意 AI 卡片右下角必须有"追问"输入框，追问时自动携带该卡片的原始 JSON 作为上下文传给 Agnes，实现连续对话而不是每次从零开始。

- 所有 AI 输出旁必须有"采纳/忽略/反馈错误"三个按钮，用户反馈数据要落地存储（即使当前是前端 mock，也要预留 localStorage 结构），为未来复盘学习中心提供数据。

## 九、验收标准（KPI，用于自查改造是否达标）

1. 打开驾驶舱页 3 秒内，用户能明确说出"今天唯一最值得参与的主线是什么"，而不是看到3条并列主线自己去猜。
2. 任意 S 级异动触发后，用户能在同一屏幕内看到"是否呼应主线 + 建议动作"，无需跳转。
3. 每个主线卡片都必须有阶段标签（启动/加速/分歧/退潮/冰点）和强度分数字，不能只有涨停家数罗列。
4. AI 输出中不得出现超过 3 句话的自由大段文字，必须是结构化要点（结论/理由/风险/置信度分行展示）。
5. 每个主线/个股卡片必须同时具备"进场理由"和"离场信号"两个板块，二者视觉权重相当。
6. 消息面任意一条快讯，用户能看到它是否命中当前主线（无需自己去资金主线页比对）。
