## 阶段 v9.115.1：认知推理层（卓越核心，一次发版）

### S1-1b 认知推理层 `server/lib/reasoning.js` 【依赖LLM:否】

- **新增文件**：`server/lib/reasoning.js`（CJS）。导出 `enrichCognition` 及 5 个子函数。
- **依赖**：③ S1-1 已完成（输入 `cog` 即 `buildCognition` 产物；`raw` 即 PG 快照；`prevCog` 为上一版认知，由 cron 保留）。

#### 数据结构（实现为普通对象，字段如下）
```
CognitionReasoning {
  coherence: { status, score, votes:[{dim,bullish,evidence}], conflicts:[] }
  drivers:   { catalyst, primaryDriver, chain:[] }
  delta:     { hasPrev, sentimentD, capitalD, leaderHeightD, trend }
  forecast:  { nextWindow, watch:[], conditions:[{iff, then}] }
  narrative: string
  provenance:{ source:"derived", asOf, confidence:0.82, caliber }
}
status ∈ {"共振进攻","多头占优","分歧注意","防御混沌"}
```

#### 子函数 1：`assessCoherence(cog) → Coherence`
```
// 跨5维度多头投票（游资看的是"共振"而非单点）
votes = [
  { dim:"情绪",   bullish: cog.sentiment.stage ∈ {启动,发酵,高潮}, evidence:`${stage}·温度${score}` },
  { dim:"资金",   bullish: cog.capital.signal ∈ {吸筹,洗盘},        evidence:`${signal}·净${net}亿` },
  { dim:"风险闸门", bullish: cog.risk.gateOpen && cog.risk.level ∈ {低,中}, evidence:`闸门${开/关}·风险${level}` },
  { dim:"龙头接力", bullish: cog.leader.relayOk,                   evidence:`${name}${height}板·接力${可/弱}` },
  { dim:"主线强度", bullish: cog.mainline.strength>=70 && rotation=="持续", evidence:`${theme}·强度${strength}` },
]
bull = votes.filter(bullish).length
status = bull>=4 ? "共振进攻" : bull==3 ? "多头占优" : bull==2 ? "分歧注意" : "防御混沌"
// 背离检测（典型假信号）
conflicts = []
if 情绪.bullish && !资金.bullish → push "情绪回暖但资金出货(量价背离)"
if !闸门.bullish && 情绪.bullish  → push "情绪亢奋但闸门未开(假进攻)"
score = clamp( round(bull/5*100 - conflicts.length*12), 0, 100 )
```

#### 子函数 2：`deriveDrivers(cog, raw) → DriverChain`
```
catalyst = raw.news.find(利好)?.title ?? cog.mainline.primaryTheme
chain = [
  `催化：${catalyst}`,
  `主线：${cog.mainline.primaryTheme}(强度${strength})`,
  `资金：${cog.capital.signal}(${net}亿)`,
  `情绪：${cog.sentiment.stage}(温度${score})`,
]
primaryDriver = cog.capital.signal=="出货" ? "资金(出货主导)"
              : cog.sentiment.stage=="高潮" ? "情绪(高潮驱动)"
              : "主线(题材驱动)"
```

#### 子函数 3：`computeDelta(cog, prevCog?) → Delta`
```
if !prevCog → { hasPrev:false, trend:"首帧，无环比", ...0 }
sentimentD    = cog.sentiment.score - prev.sentiment.score
capitalD      = cog.capital.netFlow - prev.capital.netFlow
leaderHeightD = cog.leader.height   - prev.leader.height
bits = []
sentimentD>0 → "情绪回升${sentimentD}"；<0 → "情绪回落${-sentimentD}"
capitalD>0   → "资金转正流入"；<0 → "资金转流出"
leaderHeightD>0 → "龙头晋级${leaderHeightD}板"；<0 → "龙头断板"
trend = bits.join("；") || "环比持平"
```
> 真实产品 `prevCog`：cron 每次刷新认知后保留上一版（按 version 时序），无需额外存储设计。

#### 子函数 4：`makeForecast(cog, coh) → Forecast`
```
stage = cog.sentiment.stage；l = cog.leader
if coh.status=="共振进攻" || stage=="发酵":
  nextWindow = "下一窗口(午后开盘/尾盘)：关注进攻延续性"
  watch = [`${l.name}能否封板 / 接力梯队是否扩散(tier2→tier1)`, "两市成交额是否放大", "炸板率是否抬头"]
  conditions = [
    { iff:"炸板率>20% 或 昨涨停今溢价转负", then:"高低切：减高位接力，低吸新主线首板" },
    { iff:"龙头放量烂板/尾盘炸板",          then:"接力梯队瓦解预警，清跟风" },
  ]
elif stage=="高潮":
  nextWindow = "下一窗口：警惕首分歧"
  watch = ["跟风板是否大面积回落", "龙头是否爆量滞涨"]
  conditions = [ { iff:"出现首分歧(龙头开板/封单骤减)", then:"只持不开，减仓锁定" } ]
else:  // 退潮/冰点/启动偏弱
  nextWindow = "下一窗口：防守为主，等待冰点回暖"
  watch = ["跌停数是否收敛", "是否有新题材首板试错"]
  conditions = [ { iff:"情绪冰点+新主线首板放量", then:"轻仓低吸试错" } ]
```

#### 子函数 5：`buildNarrative(cog, coh, drv, fc) → string`
```
head = `市场${coh.status}(${coh.score}分)：${drv.primaryDriver}驱动【${mainline.theme}】，资金${capital.signal}、闸门${开/关}、龙头${name}${height}板。`
conflict = coh.conflicts.length ? ` 背离提醒：${conflicts.join("；")}。` : ""
tail = fc.conditions[0] ? `前瞻：${conditions[0].iff} → ${conditions[0].then}。` : ""
return head + conflict + tail
```

#### 总入口：`enrichCognition(cog, raw, prevCog?) → CognitionReasoning`
```
coherence = assessCoherence(cog)
drivers   = deriveDrivers(cog, raw)
delta     = computeDelta(cog, prevCog)
forecast  = makeForecast(cog, coherence)
narrative = buildNarrative(cog, coherence, drivers, forecast)
provenance = { source:"derived", asOf:cog.asOf, confidence:0.82,
  caliber:"共振=跨5维度多头投票；因果=催化→主线→资金→情绪；预判=阶段×共振情景触发" }
return { coherence, drivers, delta, forecast, narrative, provenance }
```

## 阶段 v9.116.0 增量：决策直达注入游资战术

### S2-1b `assessTactics` —— 决策卡从"准入分"升级到"战术动作" 【依赖LLM:否】

- **改动文件**：`server/lib/decisionLayer.js`（③ S2-1 的 `composeDecision` 产物）+ `DecisionVerdict` 加 `tactics` 字段。
- **新增子函数**（均纯函数）：

```
Tactics { relayScore:number(0-100); stageAction:string; buyPoint:string; sellDiscipline:string; ladderPos:string }

relayEnvScore(cog):                       // 龙头接力环境分
  s=50; premium>0 →+15; leader.relayOk →+12;
  leader.height<=4 →+8 else -10;          // 高位接力空间小
  gateOpen →+10 else -18; traps空 →+5
  return clamp(s,0,100)

stageActionOf(stage):                     // 情绪周期买卖点（游资核心坐标系）
  冰点→"低吸首板试错(轻仓)"  退潮→"回避接力，管住手"
  启动→"打首板/低吸梯队"     发酵→"接力核心龙头"
  高潮→"只持不开，防爆头"     分歧→"高低切，减高位"

buyPointOf(stock, cog):                   // 买点时机
  if cog.session.phase=="竞价" || window含"09:2" → "竞价打板/低吸"
  elif stock.limitUp && stock.relay>=2 → "回封接力"
  elif !limitUp && pct∈[3,7] && bigNet>0 → "回踩低吸"
  elif limitUp && relay==1 → "首板打板(需量能)"
  else → "盘中分时确认"

sellDisciplineOf(stage):
  stage∈{高潮,分歧} → "断板即走；烂板减半；14:50未封减仓"
  else → "破均线/量能背离减仓；止损不犹豫"

ladderPosOf(stock, cog):
  tier1含该股名 → "tier1龙头"；tier2含 → "tier2跟风"；else "非主线梯队"

assessTactics(stock, cog) = { relayScore:relayEnvScore(cog), stageAction:stageActionOf(stage),
  buyPoint:buyPointOf(stock,cog), sellDiscipline:sellDisciplineOf(stage), ladderPos:ladderPosOf(stock,cog) }
```

- **验收**：
