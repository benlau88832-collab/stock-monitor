- 龙头股分类（6.3：核心逻辑/卡位/跟风蹭热点）
- 离场信号规则（6.4：炸板率+15pp/涨停数-30%/最高板下降/主力转流出）
- Agnes（2.5 Flash）结构化输出 JSON Schema + Prompt 规范（第7章）
- P0→P1→P2 迭代路线图 + 逐条编码指令清单（第10章）
