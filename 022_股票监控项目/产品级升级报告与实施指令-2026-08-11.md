## 二、A-F 六项能力：差距分析与升级方案

### A. 板块异动第一时间提醒（通达信"盘中精灵"效果）

**现状**：盘中大脑快照 5 分钟粒度（cron */5 9-15）+ 前端 30s 轮询 kv anomaly + alertBus（声音/标题闪烁/通知）+ 推送网关。规则仅两类（同板块≥3 涨停、板块涨幅>3%+主力>3 亿）+ 封单衰减（18s）。
**差距**：轮询粒度 5 分钟（游资要求秒级~分钟级）；无全板块扫描；无"精灵式"弹窗；规则覆盖不足（无炸板突变/封单异动/涨停潮突变）。

**方案设计**（搜索验证：东财 push2ex 四池接口实测参数 + 东财风控阈值）：
- 服务端新增 **2-5s 串行轮询**（9:25-15:00 交易日）：push2ex 四池（getTopicZTPool/ZBPool/DTPool/YesterdayZTPool，参数 ut=7eea3edcaed734bea9cbfc24409ed989&dpt=wz.ztzt&sort=fbt:asc&date=YYYYMMDD，pagesize≤10000）+ 板块涨幅榜（clist/get fs=m:90+t:2）。**遵守东财风控：QPS≤2、串行、随机抖动 1-3s、经 /api/proxy + 分级冷却**（复用 jsonpQueue 同构逻辑）
- 事件引擎升级（server 端，复用现有 anomalyTier 分级 S/A/B）：
  - 新增规则：板块 5 分钟涨幅突变（>X% 且创日内新高）、板块涨停家数突变（+N 只/5min）、炸板率突变、封单异动（封单金额变化率超阈值）、昨日涨停今日集体低开/高开（竞价映射）
  - 冷却：同板块同类型 30 分钟去重（现有 kv HHMM 比较机制复用）+ 推送每轮最多 3 条（critical 优先）
- 前端"盘中精灵"浮层：右下角常驻迷你条 + 事件弹窗（S 级红闪/A 级高亮/B 级列表），复用 alertBus 声音/通知
- 竞价阶段（9:15-9:25）单独通道：竞价异动（高开/低开幅度榜）提前提醒

**子任务**：
- T-A1 服务端四池秒级轮询器（cron 新调度 + 事件落 PG/kv）→ ✅ 已交付 v9.102.0（intradaySprint.js：四池串行 QPS≤2+1.5-3s 抖动，*/2s 调度 busy 跳过+PG lock；测试事件落库 anomaly_latest 实测通过）
- T-A2 事件规则引擎升级（5 条新规则 + 冷却去重）→ ✅ 已交付 v9.102.0（intradayRules.js：R1 板块涨停潮/R2 全局涨停潮/R3 炸板突变/R4 封单异动 + 30min 冷却；6 单测全过；R5 竞价映射预留）
- T-A3 前端精灵浮层（弹窗/迷你条/声音）→ ✅ 已交付 v9.102.0（SpriteOverlay.tsx：右下角迷你条+5s 轮询 anomaly_latest+S 级红闪弹窗 6s 自动收起+alertBus 声音；浏览器实测迷你条显示测试事件）
- T-A4 推送分级（critical/warning/info 三档路由）→ ✅ 已交付 v9.102.0（S→critical/A→warning/B→info，每轮最多 3 条 critical 优先）

### B. 识别当日主线与可上车标的（不追高、做低吸、重胜率赔率）

**现状**：主线强度六维评分✓、首选/接力/低吸角色分桶✓、仓位定量化✓、recTracker T+1/T+3 回填✓（命中率统计有，但**无赔率/期望值显性化**）；低吸信号是文案级（"回踩5日线/竞价弱转强"）。
**差距**：胜率与赔率未同屏展示（游资决策核心是"胜率×赔率=期望值 EV"）；低吸标的筛选无量化信号；主线级历史表现无回测。

**方案设计**：
- **EV 期望值面板**（recTracker/signalLedger 扩展）：每标的/每主线显示 `历史胜率 X%（n 样本）· 赔率 Y:1 · 期望值 EV Z%`——胜率=T+1 正收益比例，赔率=平均盈/平均亏，EV=胜率×平均盈-（1-胜率）×平均亏；样本<20 显示"积累中"（沿用现有诚实标注风格）
- **低吸信号引擎**（新 lib/lowAbsorb.ts 纯函数）：候选=主线内首板/二板回踩标的，信号组合：回踩 5 日线不破 + 缩量（量比<0.8）+ 主力 5 日净流入 + 炸板率环境允许（炸板率<30%）；输出"低吸区价格/止损/目标"三线
- **主线级胜率回测**：同强度分区间（60-70/70-80/80+）× 同阶段（启动/发酵/分歧）的历史主线次日/3 日胜率与赔率（数据源：zt_snapshot 7 天 + decision_log + market_daily 已补跑）
- **不追高硬约束**：追高（打板）只在 S 级卡位且封单健康时允许；默认输出低吸/接力清单（现有 stockPicker 已分桶，增强其"追高警告"展示）

**子任务**：
- T-B1 期望值统计纯函数 + 单测（胜率/赔率/EV）→ ✅ 已交付 v9.101.1（evStats.ts，5 用例：正常/积累中/空/全赢/全亏）
- T-B2 标的卡与主线卡显示 EV 面板 → 验证：浏览器实测 n≥20 显示真实统计；n<20 显示积累中
- T-B3 低吸信号引擎（回踩+缩量+资金回流组合）→ ✅ 已交付 v9.101.1（lowAbsorb.ts，6 用例：四信号/破位/放量/流出/环境/阈值覆盖）
- T-B4 主线级回测（zt_snapshot+decision_log 聚合）→ 验证：输出同强度主线的历史胜率表

### C. 盘中新闻/政策面 LLM 分析（提高参与主线和推荐标的的胜率赔率）

**现状**：情报分析台手动/定时触发（LLM 或规则版）、themeNewsScore 消息维度评分、快讯利好利空分级、事件三级分类（盘后批量）。**盘中 LLM 实时介入弱、新闻→标的→决策链未闭环**。
**差距**：盘中无自动 LLM 分析；新闻分级后不下探到"影响哪些标的/主线"；LLM 慢（35s-90s）与盘中时效矛盾。

**方案设计**：
- **盘中情报自动触发**：llmNewsIntelligence 盘中每 30 分钟自动跑（9:30-15:00），参数化（可开关、可调频）；盘后完整版保持
- **新闻→标的闭环**：news 已有 sentiment/boards；新增"新闻命中的主线/标的"聚合（新闻标题关键词 × 概念白名单 504 × 涨停池成分），命中即入"消息驱动候选"（与主线作战卡联动，aiConclusionStore 复用）
- **LLM 快评分层**：重要新闻（涨停池相关/政策突发/行业龙头公告）触发 LLM 快评（≤200 字，"利好/利空/影响链/参与建议"四段式），失败降级规则版（P1-06 教训：降级标注必须明确）
- **时效策略**：盘中 LLM 用轻量 prompt（快评非深研）；90s 超时前端 95s 已有；并发 2 节流（stockPicker 已有模式）

**子任务**：
- T-C1 盘中情报定时触发（cron 30min + 开关）→ 验证：盘中 kv 出现今日情报轮次
- T-C2 新闻×主线×标的联动聚合 → 验证：浏览器新闻卡显示"影响主线/标的"标记；curl 聚合端点
- T-C3 LLM 快评任务（aiPrompts 新模板 + 降级）→ 验证：触发重要新闻生成快评；LLM 失败时规则版标注

### D. 标的资金识别（诱多/假摔/强势介入）+ 多场景情绪面识别（外围映射/政策突发/行业突破/个股利好/历史回测）

**现状**：trapDetector（诱多 9.5% 阈值问题已记）、fundNewsReconcile（资金-消息对账）、anomalyTier（S/A/B）、seatBehavior、封单衰减。**外围映射完全空白（grep 无 AXT/映射）、无相似历史回测、LLM 情绪识别未接搜索**。
**差距**：客户点名的"AXT 大涨→云南锗业""美国限制→某行业利好/利空""特朗普政策→产业链突发情绪面"全部无覆盖。

**方案设计**（搜索验证：AXT→云南锗业映射实证、事件研究法 AR/CAR、盘口量化特征）：
- **T-D1 外围映射表**（新 lib/overseasMap.ts + PG 表）：结构 `{外盘标的/事件源, 映射A股板块ID, 标的池, 传导链(需求→环节→标的), 强度权重, 时滞(隔夜→次日开盘), 置信度}`。首批内置 20+ 条实证映射（AXT→云南锗业/锗概念、英伟达→CPO/光模块、美光→存储、苹果→果链、特斯拉→汽零/机器人、美债收益率→黄金/成长、原油→油服/化工、美股 AI→算力链）。数据源：东财外盘行情（push2delay 兜底——push2 断源已知）+ 手动校准（搜索指出无权威公开映射表，需自建+持续人工校准）
- **T-D2 隔夜映射巡检**（cron 9:05 盘前 + 15:05 盘后）：抓隔夜美股异动（涨跌幅>X% 且成交放量），匹配映射表 → 生成"今日映射提示"（板块/标的/传导逻辑/置信度）→ alertBus + 推送
- **T-D3 相似历史回测（事件研究）**（新 lib/eventStudy.ts）：事件库 = {政策发布/外围异动/公告/制裁}，按"事件类型+方向"标签归档；对每类事件算次日/3 日相关板块平均涨跌幅、胜率、样本数 → 输出"N 次同类事件后板块次日平均 X%（胜率 Y%）"（事件窗口 [-10,10] 简化版：先做次日/3 日，不做完整 AR/CAR）
- **T-D4 盘口特征升级**（trapDetector 扩展）：封成比（封单/成交）、封单/流通市值比、封单变化率（撤单速度）、炸板后大单流向、换手率组合 → 三类信号：**强势介入**（封单占比高且稳定+大单净流入+换手温和）/ **诱多**（封单大但快速撤单+大单流出）/ **假摔**（炸板但大单未出+尾盘回封）；叠加情绪周期位置调阈值（情绪冰点时收紧介入阈值）
- **T-D5 LLM 情绪面推理**（assistantAgent 增强）：新增"事件→A股影响"工具——输入事件（如"特朗普宣布加征 X 关税"），LLM 结合内置映射表+搜索（妙想 mx-search 已有接入）+PG 历史数据，输出"受益链/受损链/影响强度/操作建议"，带降级标注。客户列举的开放式场景（政策突发/行业突破/外围映射/个股利好公告）都走这个工具

**子任务**：
- T-D1 映射表结构 + 首批 20 条数据（含 AXT→云南锗业实证链）→ 验证：表结构单测 + 数据完整性
- T-D2 隔夜巡检 cron + 映射提示 → 验证：盘前提示生成（curl kv）；映射匹配单测
- T-D3 事件研究纯函数（次日/3 日统计）+ 事件库 → ✅ 已交付 v9.101.1（eventStudy.ts，3 用例：聚合统计/空/无数据过滤；事件库接入待 T-D2/E5 批次）
- T-D4 盘口特征三分类（纯函数）→ ✅ 已交付 v9.101.1（boardTrap.ts，7 用例：诱多/假摔×2/强势/不稳定/优先级/阈值覆盖）
- T-D5 LLM 情绪推理工具（aiPrompts 模板 + PG 工具注册）→ 验证：AskAI 实测"AXT 大涨怎么看云南锗业"得到映射链回答；降级标注存在

## 五、风险与约束

1. **东财风控**：秒级轮询必须串行 QPS≤2 + 随机抖动 + 分级冷却，否则封 IP（搜索实证阈值：>5 次/秒、并发≥10、1 分钟≥200 封禁）。四池轮询 2-5s 可行；全市场板块列表轮询需限流分批
2. **push2 断源持续**（WAF 动态风控）：秒级轮询依赖 push2ex——实测 push2ex 当前正常（health 100%），但需分级冷却保护 + 断源时事件引擎降级为 5 分钟粒度（不硬撑）
3. **外围数据源**：东财外盘行情（美股个股/指数）走 push2/push2delay——断源时映射巡检延迟；映射表自建需持续人工校准（搜索确认无权威公开表）
4. **LLM 稳定性**（empty content/超时）：所有 LLM 任务带降级；快评用轻量 prompt 控时长；服务端 max_tokens 核对列入第一批
5. **政策抓取**：gov.cn 有反爬风险——用现有快讯通道+手动导入兜底；语料库首批人工导入（十五五/十四五全文）
6. **产品边界**：不承诺"保证胜率"；所有统计标注样本量与口径（沿用"样本不足/估算值*"诚实标注风格）；免责声明保留
